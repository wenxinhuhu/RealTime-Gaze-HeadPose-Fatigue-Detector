# VisionGuard 👁️  
**Real-Time Gaze Tracking, Head Pose Analysis, Fatigue Detection**

本项目为一个基于本地摄像头的实时视线方向识别、头部姿态分析与疲劳检测框架，为智能监控与人机交互提供基础支持。

---

## ✨ 核心功能
- **视线方向追踪**: 实时检测用户视线方向（左/右/上/下/中心）。  
- **头部姿态分析**: 识别点头、摇头动作及头部倾斜角度。  
- **疲劳检测**: 综合眨眼频率、闭眼时长、点头频率、是否打哈欠判断疲劳状态。  
- **低延迟**: 使用本地摄像头实时处理。
